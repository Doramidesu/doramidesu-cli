# Doramidesu CLI

Build Your Future with Confidence.

A beginner-friendly CLI to bootstrap modern web projects with guided setup and best practices.

## Features

- 🚀 Initialize new projects
- 🔍 Environment diagnostics (`doctor`)
- 📖 Built-in help menu
- 📦 Easy-to-use command line interface

## Installation

```bash
npm install -g doramidesu
```

## Usage

```bash
doramidesu
```

```bash
doramidesu init
```

```bash
doramidesu doctor
```
